# 行为准则 / Code of Conduct

本准则适用于本仓库的 issue、pull request、discussion、review、release 以及
其他以本项目名义进行的交流。参与即表示同意本准则。

This code applies to issues, pull requests, discussions, reviews, releases and
other communication made in this project's name. Participation implies agreement.

## 期望行为 / Expected behaviour

- 尊重不同经验、语言、时区与观点；对事不对人；
- 提供可复现的技术信息，明确区分事实、假设与推测；
- 尊重版权、商标、合同与当地法律；不要求他人提供固件、密钥或 dump；
- 在公开渠道删除个人信息、序列号、绝对路径与未公开材料；
- 接受维护者以范围、证据或法律理由拒绝或关闭讨论。

- Respect different experience, language, time zones and viewpoints; critique
  ideas, not people.
- Provide reproducible technical information and separate facts, hypotheses and
  speculation.
- Respect copyright, trademarks, contracts and local law; never ask others for
  firmware, keys or dumps.
- Remove personal data, serial numbers, absolute paths and unpublished material
  from public channels.
- Accept that maintainers may decline or close discussions for scope, evidence or
  legal reasons.

## 不可接受的行为 / Unacceptable behaviour

- 骚扰、歧视、人身攻击、威胁、恶意曝光他人信息；
- 发布或索要固件、密钥、dump、泄露代码、可刷写改后镜像；
- 提供绕过签名/校验/付费功能或攻击第三方设备的教程；
- 垃圾信息、恶意刷屏、故意浪费维护者时间；
- 违反适用法律或 GitHub 政策的行为。

- Harassment, discrimination, personal attacks, threats, doxxing.
- Posting or requesting firmware, keys, dumps, leaked code or flashable images.
- Tutorials for bypassing signatures/verification/paid features, or attacking
  third-party devices.
- Spam, deliberate disruption, or wasting maintainers' time.
- Violating applicable law or GitHub policy.

## 执行 / Enforcement

维护者可采取提醒、编辑/删除内容、锁定讨论、拒绝贡献、临时或永久封禁等措施。
举报请通过仓库的私密渠道（见 [SECURITY.md](SECURITY.md)）或 GitHub 的举报功能；
不要在公开 issue 中曝光个人信息。维护者会按善意与比例原则处理，并尽量保护举报人。

Maintainers may warn, edit/remove content, lock threads, reject contributions, or
temporarily/permanently ban participation. Report concerns through the private
channel in [SECURITY.md](SECURITY.md) or GitHub's reporting tools; do not expose
personal data in public issues. Enforcement will be proportionate and
good-faith, and reporters will be protected as far as practicable.
